# Security Policy

## Scope

This public repository contains the Mycroft advisory method and project
documentation. It must never contain client material, engagement records,
credentials, financial details, or private working notes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not include
potentially sensitive details in public issues, pull requests, or discussions.

Include the affected file or commit, a minimal reproduction, impact, and any
mitigation already applied. Reports are triaged before a public disclosure or
fix is published.
